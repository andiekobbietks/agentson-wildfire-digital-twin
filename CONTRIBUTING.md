# Contributing

Thank you for helping improve the AgentSON Wildfire Digital Twin research scaffold.

## Before opening a pull request

- Read the [PRD](docs/PRD.md), [architecture](docs/ARCHITECTURE.md), and [security guide](docs/SECURITY.md).
- Open an issue for substantial changes to scope, architecture, datasets, or dependencies.
- Explain the evidence behind technical and scientific claims.
- Keep simulation-only results clearly labelled.

## Contribution expectations

1. Prefer small, reviewable changes.
2. Include tests for parsers, transformations, schemas, and adapters.
3. Record versions and reproducibility steps.
4. Preserve source attribution and licence notices.
5. Do not commit secrets, personal data, or unlicensed assets.
6. Distinguish observed, reanalysis, forecast, derived, and synthetic data.
7. Avoid claims of operational accuracy or safety without independent evidence.

## Pull request checklist

- [ ] Scope and rationale are clear.
- [ ] Documentation is updated.
- [ ] Tests or validation steps are included.
- [ ] Dependencies and licences are recorded.
- [ ] Data provenance is preserved.
- [ ] Limitations and known failure modes are stated.
- [ ] No credentials or restricted information are included.

## Questions

Use GitHub Issues for project questions and proposed work. For security-sensitive reports, contact the maintainer privately.
